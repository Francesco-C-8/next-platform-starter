1. Executive Summary & KPI attesi

Cosa cambia e quanto può rendere.

Obiettivo: trasformare il flusso d'acquisto attuale di rocard.it (WooCommerce + WoodMart standard) in un funnel ottimizzato con 12 pattern CRO verificati, copy scientifico, e una landing dedicata al programma abbonamento (asset oggi sottoutilizzato).

+18-35%
CVR (Conversion Rate)
+12-22%
AOV (Average Order Value)
+8-15%
LTV (Lifetime Value)

Stime basate su benchmark di settore (e-commerce food/pet/farmacia IT) per implementazioni complete. La proiezione conservativa è +12% CVR · +10% AOV · +6% LTV; quella ottimista +35% CVR · +22% AOV · +15% LTV.

3. Matrice impatto / sforzo

Priorità in 3 livelli — fai prima i P0, poi P1, infine P2.

P0 Quick wins · alto impatto, basso/medio sforzo

① Express Pay (Apple/Google/PayPal) sopra il form

Già nativo in Stripe WooCommerce Gateway. Spostare in cima al checkout.

Sforzo: ½ giornata · Impatto: +15-25% CVR mobile

② Progress Stepper visibile

Componente HTML/CSS · da inserire come header del template checkout.

Sforzo: 1 giornata · Impatto: −12-20% drop-off

③ Free Shipping Bar dinamica

Plugin Advanced Free Shipping Bar (free) oppure custom JS sul cart.

Sforzo: ½ giornata · Impatto: +6-12% AOV

P1 Driver principali · medio impatto, medio sforzo

④ Bundle Pricing 1/3/5

WooCommerce Product Bundles o YITH Dynamic Pricing. Custom UI per cards.

Sforzo: 3 giornate · Impatto: +10-18% AOV

⑤ Order bumps (Protezione/Prioritaria)

CartFlows o template custom in cart-totals.php.

Sforzo: 2 giornate · Impatto: +35-50% attach rate

⑥ Thank-you page custom

Hook woocommerce_thankyou + template. Aggiungere timeline + order bump + voucher + referral.

Sforzo: 4 giornate · Impatto: +15-22% AOV totale

P2 Long-term · alto sforzo, impatto consolidato

⑦ Landing Abbonamento dedicata

Pagina WordPress con calcolatore JS, FAQ, comparison table. Integrazione con WooCommerce Subscriptions già attivo.

Sforzo: 3-4 giornate · Impatto: +LTV ×2,5 sui convertiti

⑧ Scientific spec ACF su PDP

Custom fields per categoria · render via shortcode.

Sforzo: 2-3 giornate + content · Impatto: +6-10% PDP→ATC

⑨ Referral programma

Plugin AutomateWoo Refer-a-Friend.

Sforzo: 2 giornate · Impatto: K-factor 0.04-0.08

5. Step 1 — Carrello

File di riferimento: /rocard/cart.html

Pattern implementati

  • Stepper a 4 fasi sticky in alto · CSS pure
  • Product row con immagine, titolo, descrizione scientifica, reviews mini (4,8 · 3.412 verificate), badge stock, badge consegna, qty stepper
  • Scientific spec box con composizione miscela, tostatura, macinatura, Cremosity Index — terminologia da inserire via ACF
  • Free shipping bar dinamica con barra di progresso colore-coded (verde sbloccato, giallo se manca)
  • Cutoff timer countdown "Ordina entro 02h 17m 36s per spedizione oggi"
  • Bundle pricing 1/3/5 con tag "PIÙ SCELTO −9%" e "BEST VALUE −17%" sul migliore
  • Urgency social proof "22 persone hanno questo prodotto nel carrello in questo momento"
  • Cross-sell 3-card con prodotti reali Rocard (Borbone Rossa, Nera, Lavazza)
  • Order bumps sidebar Protezione spedizione (1,90€ pre-checked), Spedizione prioritaria (3,90€)
  • Subscription nudge bottom-right "Abbonati e risparmia 2% extra"

6. Step 2 — Spedizione

File: /rocard/checkout.html

Pattern

  • Express Pay top-of-form (Apple Pay, Google Pay, PayPal Express)
  • Trust strip 4 chip subito sotto i pulsanti express
  • Form sezionato: Contatto → Indirizzo → Metodo spedizione (no "Metodo Pagamento" duplicato come nei tuoi mockup)
  • Email-first con hint "ti invieremo qui la conferma ordine e il tracking"
  • Real-time inline validation con check verde sui campi compilati correttamente
  • CAP autocomplete consigliato via Google Places API (hint "Inizia a digitare — autocompletiamo via Google Maps")
  • Metodo spedizione a 2 card: Standard gratis (default) / Express 24h (+3,90€)
  • Summary sticky destra con cutoff timer e badge SSL/Reso/Supporto/4,8/5

Plugin consigliato

Sostituire il checkout WooCommerce standard con FunnelKit Funnel Builder (preferito per UX e Apple Pay nativo) o CartFlows. Entrambi supportano il pattern.

7. Step 3 — Pagamento

File: /rocard/payment.html

Pattern

  • Reservation timer 10 min "Stiamo riservando il tuo prodotto" — banner blu in alto
  • Recap prodotto con immagine + consegna stimata + totale evidenziato
  • Express Pay reiterato sopra al form carta
  • Metodi pagamento a fisarmonica: Carta (default expanded), PayPal, Klarna 3 rate, Bonifico SEPA
  • Social proof in-line: "78% dei clienti sceglie la carta — è il metodo più veloce"
  • Auto-format numero carta (gruppi 4-4-4-4), scadenza (MM/AA), CVV maxlength 4
  • Tooltip CVV "3 cifre sul retro" — riduce errori 40%
  • Reassurance "I tuoi dati sono protetti con SSL 256-bit · Non memorizziamo i dati della tua carta · Transazione gestita da Stripe (PCI-DSS Level 1)"
  • Testimonial card "★★★★★ Ordine arrivato in 24h..." da Trusted Shops
  • Coupon collapsed in summary (no campo visibile = no incentivo a cercare codice fuori dal sito)
  • Urgency mantenuta "Prodotto popolare: 22 ordini nell'ultima ora"

Note importanti

  • Klarna 3 rate ha un'incidenza media +9-14% su categoria pet care/casa fascia 60-150€. Va attivato.
  • Bonifico SEPA istantaneo (es. tramite Mollie o Stripe) è gratuito e veloce — consigliato per ordini >100€.

8. Step 4 — Thank-you (POST-PURCHASE)

File: /rocard/thank-you.html

Questa pagina è oggi la più sottoutilizzata di rocard.it. È il momento di massima fiducia → massima propensione ad acquistare ancora.

Pattern (in ordine di apparizione)

  1. Hero conferma con check animato + "Grazie [Nome]!" + numero ordine in mono-font
  2. Timeline 4-step Ordine ricevuto → In preparazione (active, pulse) → In spedizione → Consegnato (con date)
  3. Delivery & email 2 cards (consegna stimata + email confermata)
  4. POST-PURCHASE ORDER BUMP 15-min countdown — "Offerta riservata clienti appena acquistati" con 10% sconto extra e "stesso pacco, una sola spedizione". Plugin: WPSwings One Click Upsell.
  5. Subscribe & Save card con CTA "Attiva abbonamento" → link a /subscription.html
  6. Voucher prossimo ordine ROCARD10 (10% · 30 gg) in formato ticket dashed con copia in clipboard
  7. Referral "Regala 10€ ricevi 10€" con condivisione WhatsApp/Email/Link
  8. Account creation 1-click usando email già nota (no password obbligatoria) → integrazione Magic Link
  9. NPS emoji 5 livelli → webhook su Google Sheets / Hotjar
  10. Support cards Email / Telefono / Chat con tempi di risposta

9. Landing Abbonamento Rocard

File: /rocard/subscription.html

Rocard ha già attivo WooCommerce Subscriptions ("abbonati per risparmiare fino al 2%" presente su ogni prodotto) ma manca una landing dedicata che spieghi il programma e ne aumenti l'adoption.

Sezioni della landing

  • Hero "Mai più scorte finite. Mai più prezzo pieno." + CTA → calcolatore
  • Stat band −2% / 0€ attivazione / 1 clic annulla / 24/7 supporto
  • 4 step "Come funziona" visuali
  • Calcolatore risparmio annuale JS dinamico — input categoria + frequenza, output spesa standard vs risparmio
  • Tabella comparison Acquisto singolo vs Abbonamento (9 righe di benefit)
  • Categorie consigliate 6 card (Caffè, Pet, Farine, Auto, Casa, Giardinaggio)
  • 3 testimonial verificati
  • FAQ 8 domande (costo, vincoli, modifiche, prezzo, pagamento, %catalogo, fedeltà)

  • Banner home rotante con "Risparmia 2% per sempre"
  • CTA dedicato nella thank-you page (già implementato nel prototipo)
  • Nudge nel cart sidebar (già implementato nel prototipo)

11. Hook PHP & snippet

Punti di estensione principali per personalizzare WooCommerce senza modificare i template di tema.

Bundle pricing custom (alternativa a Product Bundles)

// functions.php · prezzo dinamico in base a quantità add_filter('woocommerce_cart_item_price', 'rc_bundle_price', 10, 3); function rc_bundle_price($price, $cart_item, $cart_item_key) { $qty = $cart_item['quantity']; $product = $cart_item['data']; $cat_ids = $product->get_category_ids(); // Applica bundle pricing solo su categoria Caffè if (in_array(CAT_CAFFE_ID, $cat_ids)) { if ($qty >= 5) $unit = 19.90; elseif ($qty >= 3) $unit = 21.90; else $unit = 23.96; $product->set_price($unit); } return wc_price($product->get_price()); }

Order bumps charge nel totale

add_action('woocommerce_cart_calculate_fees', 'rc_add_bumps'); function rc_add_bumps() { if (WC()->session->get('rc_shipping_protection')) { WC()->cart->add_fee('Protezione spedizione', 1.90); } if (WC()->session->get('rc_priority_shipping')) { WC()->cart->add_fee('Spedizione prioritaria', 3.90); } }

Free shipping bar via shortcode globale

add_shortcode('rocard_ship_bar', function() { $target = 49.90; $subtotal = WC()->cart->get_subtotal(); $pct = min(100, ($subtotal / $target) * 100); $left = max(0, $target - $subtotal); ob_start(); ?> <div class="rc-shipbar <?= $left>0?'unmet':'' ?>"> <span><?= $left>0 ? "Ti mancano <b>".wc_price($left)."</b> per spedizione gratuita" : "Spedizione gratuita sbloccata!" ?></span> <div class="progress"><div class="bar" style="width:<?= $pct ?>%"></div></div> </div> <?php return ob_get_clean(); });
